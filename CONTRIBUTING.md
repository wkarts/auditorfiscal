# Contribuição

Use branches `feature/*`, `fix/*`, `release/*` e `hotfix/*`. Commits seguem
Conventional Commits. Toda alteração exige Pull Request, testes, lint, build das
imagens, smoke test e revisão.

Mudanças fiscais devem incluir fonte normativa, vigência, teste unitário e dados
de regressão exclusivamente sintéticos. Nunca versione XMLs, relatórios,
identificadores, e-mails, endereços ou nomes de clientes.
